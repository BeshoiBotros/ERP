Why this module

Daily figures you can trust and sign off.

01 / RECORD

One sheet per day and tag

Each company, day and category tag (e.g. Perfumes) gets exactly one sheet, enforced in the database. Lines snapshot the product cost when entered, so later cost changes never rewrite past days.

02 / CONTROL

A sign-off nobody can skip

Users confirm, managers close. Status changes only through those buttons, never a direct write, and a confirmed day's lines are locked for everyone until a manager reopens it. Who confirmed and closed is stamped on the sheet.

03 / INSIGHT

Every number opens its lines

The dashboard compares any period with the one before, charts the daily trend and the top products, and every card, bar, day and row opens the exact lines behind it. The same figures print as PDF or export to Excel.

Day in the life

A store keeper records the day; a manager closes it.

  1. Open today's sheet and press Copy Previous Sheet for a usual day, or Import Lines from a CSV or XLSX file (English or Arabic headers). Adjust quantities and add returns.
  2. Press Confirm. The lines lock and the sheet waits for a manager. A draft left past its day gets a reminder activity automatically.
  3. The manager reviews and presses Close Day, then prints the sheet with its signature lines if a paper trail is needed.
  4. At month end, open the dashboard, pick the period, and export the summary as PDF or every line as Excel.

What is inside

Built to do the job, end to end.

  • Daily sheets with disbursed and returned tabs, stored totals, chatter and approval stamps.
  • Category tags with colours and optional product-category restrictions, enforced on the server.
  • All-or-nothing CSV / XLSX import: every problem is listed with its row number and nothing is saved until the file is clean.
  • Line analysis in pivot, graph and list views; a daily reminder for overdue drafts.
  • Live dashboard: today, yesterday, week, month, last 30 days or a custom range, compared with the previous period; multi-company with currency conversion.
  • PDF daily sheet and period summary, and a five-sheet Excel export (summary, by day, products, by tag, every line).
  • User and Manager roles, read-only access for the EH Auditor, company isolation, and a full automated test suite.
  • Complete Arabic translation, with a right-to-left dashboard.

Honest about the edges

What this does not do, so nothing surprises you.

  • It tracks cost; it does not post journal entries or move stock. Inventory levels in the Inventory app are not touched.
  • Quantity totals add up units across different products, so treat them as an indicator; cost totals are exact.
  • Across companies with different currencies, dashboard amounts are converted at the period-end rate, not each line's own date.
  • Returns are not linked to the disbursement they reverse; they are recorded per day like any other line.
